## 交易系统全面代码审计（14:15启动）

### 🔴 P0 严重问题

**1. 趋势跟踪止损逻辑反转**
- 文件：`strategies/trend_strategy.py`
- 问题：`if profit_pct <= -cfg['stop_loss']` 其中 stop_loss=-6.0
- 展开：`profit_pct <= -(-6.0)` = `profit_pct <= 6.0` → 盈利<6%全部误触发止损！
- 真正亏损-6%时反而不触发
- 修复：改为 `if profit_pct <= cfg['stop_loss']:`

**2. 趋势策略 volume_ratio 字段映射错误**
- 文件：`strategies/trend_strategy.py` 第91行
- 问题：`volume_ratio` 和 `pe` 都用了 fields[39]（PE字段）
- 量比实际是 fields[49]
- 影响：PE=20的股票被当成量比20x
- 修复：`'volume_ratio': float(fields[49]) if len(fields) > 49 and fields[49] != '-' else 1.0`

### 🟡 P1 中等问题

**3. overnight_screener change_pct 字段错误**
- fields[31] = 涨跌额（元），fields[32] = 涨跌幅（%）
- 当前用fields[31]标注为change_pct，实际是涨跌额
- 影响有限（选股主要用akshare强势股池数据），但函数返回值语义错误

**4. MEMORY.md vs 代码参数不一致**
- 一夜持股法止损：MEMORY记录-3%，代码实际-2%
- 买入窗口：MEMORY记录14:30-14:55，代码实际14:50-14:55
- 需要对齐（以代码为准还是以文档为准待确认）

**5. 双gunicorn master进程**
- PID 551503（May25）和 PID 1391713（May27）同时存在
- 旧进程可能加载旧代码
